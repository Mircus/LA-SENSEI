## Exercises

### E02.01 — Computational

Construct the full multiplication table of $\mathbb{F}_4$ and find the inverses of its nonzero elements.

**Companion status:** Runnable worked instance.

### E02.02 — Structural

Prove that $a^{p^n}=a$ for every $a\in\mathbb{F}_{p^n}$, beginning with the fact that the multiplicative group has $p^n-1$ elements.

**Companion status:** Reader proof / discussion / exploration.

**Suggested method:** Give the abstract argument first; if computing examples, state which additional assumptions you used.

### E02.03 — Computational

In $\mathbb{F}_4$, compute the trace and norm of each element to $\mathbb{F}_2$.

**Companion status:** Runnable worked instance.

Check result: `la-sensei chapter 2` → `E02.03`.

### E02.04 — Conceptual

Explain why $\mathbb{F}_2^2$ and $\mathbb{F}_4$ are isomorphic as $\mathbb{F}_2$-vector spaces but not as rings if the first carries coordinatewise multiplication.

**Companion status:** Reader proof / discussion / exploration.

**Suggested method:** Give the abstract argument first; if computing examples, state which additional assumptions you used.

### E02.05 — Exploratory

Build $\mathbb{F}_8$ from $x^3+x+1$. Write the Frobenius orbit of $\alpha$ and compute its trace.

**Companion status:** Runnable worked instance.
