# Chapter 1: Who needs the real numbers?

Source: *Linear Algebra: One Language, Many Dialects*, draft manuscript (October 2026).
Exercise numbering follows the source chapter exactly. Proof-based problems are intentionally not replaced by numerical examples.

Run the workshop: `la-sensei chapter 1`

## Exercises

### E01.01 — Conceptual

Explain why $\mathbb{Z}/4\mathbb{Z}$ fails to be a field, and identify the step in Gaussian elimination that can fail there.

**Companion status:** Reader proof / discussion / exploration.

**Suggested method:** Give the abstract argument first; if computing examples, state which additional assumptions you used.

### E01.02 — Computational

Count $|\operatorname{GL}(2,\mathbb{F}_3)|$. Then count the lines through the origin in $\mathbb{F}_3^2$.

**Companion status:** Runnable worked instance.

Check result: `la-sensei chapter 1` → `E01.02`.

### E01.03 — Structural

Prove rank–nullity over an arbitrary field directly by extending a kernel basis.

**Companion status:** Reader proof / discussion / exploration.

**Suggested method:** Give the abstract argument first; if computing examples, state which additional assumptions you used.

### E01.04 — Exploratory

Draw the seven-point Fano plane using the seven nonzero vectors of $\mathbb{F}_2^3$. Verify that any two distinct points lie on exactly one line.

**Companion status:** Runnable worked instance.

Check result: `la-sensei chapter 1` → `E01.04`.
