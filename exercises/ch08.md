# Chapter 8: Symmetry is linear algebra with a group attached

Source: *Linear Algebra: One Language, Many Dialects*, draft manuscript (October 2026).
Exercise numbering follows the source chapter exactly. Proof-based problems are intentionally not replaced by numerical examples.

Run the workshop: `la-sensei chapter 8`

## Exercises

### E08.01 — Structural

Check directly that $\overline P$ in the averaging argument commutes with every $\rho(h)$.

**Companion status:** Reader proof / discussion / exploration.

**Suggested method:** Give the abstract argument first; if computing examples, state which additional assumptions you used.

### E08.02 — Computational

List all six invertible $2\times2$ matrices over $\mathbb{F}_2$ and identify their permutations of the three nonzero vectors.

**Companion status:** Runnable worked instance.

Check result: `la-sensei chapter 8` → `E08.02`.

### E08.03 — Conceptual

State exactly where Maschke's proof fails over $\mathbb{F}_p$ when $p\mid|G|$.

**Companion status:** Reader proof / discussion / exploration.

**Suggested method:** Give the abstract argument first; if computing examples, state which additional assumptions you used.

### E08.04 — Challenge

Determine the invariant subspaces in the $C_p$ example.

**Companion status:** Runnable worked instance.

Check result: `la-sensei chapter 8` → `E08.04`.

### E08.05 — Exploratory

For a given finite symmetry group acting on a data space, count the parameters of an intertwining linear layer by decomposing the representations when Maschke's theorem applies.

**Companion status:** Reader proof / discussion / exploration.

**Suggested method:** Give the abstract argument first; if computing examples, state which additional assumptions you used.
