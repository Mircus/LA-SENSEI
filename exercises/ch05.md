# Chapter 5: Duality, quotients, and universal constructions

Source: *Linear Algebra: One Language, Many Dialects*, draft manuscript (October 2026).
Exercise numbering follows the source chapter exactly. Proof-based problems are intentionally not replaced by numerical examples.

Run the workshop: `la-sensei chapter 5`

## Exercises

### E05.01 — Conceptual

Explain why a chosen basis gives $V\cong V^*$ but the isomorphism depends on the basis.

**Companion status:** Reader proof / discussion / exploration.

**Suggested method:** Give the abstract argument first; if computing examples, state which additional assumptions you used.

### E05.02 — Structural

Prove $(V/U)^*\cong U^\circ$ without choosing coordinates.

**Companion status:** Reader proof / discussion / exploration.

**Suggested method:** Give the abstract argument first; if computing examples, state which additional assumptions you used.

### E05.03 — Computational

Write the matrix of $T^*$ when $T:\mathbb{F}_3^2\to\mathbb{F}_3^3$ has matrix $\begin{pmatrix}1&2\\0&1\\2&2\end{pmatrix}$.

**Companion status:** Runnable worked instance.

Check result: `la-sensei chapter 5` → `E05.03`.

### E05.04 — Structural

Show $V\otimes_{F} F\cong V$ using the tensor product universal property.

**Companion status:** Reader proof / discussion / exploration.

**Suggested method:** Give the abstract argument first; if computing examples, state which additional assumptions you used.

### E05.05 — Challenge

Exhibit a nonzero tensor in $\mathbb{R}^2\otimes\mathbb{R}^2$ that cannot be written as a single pure tensor $v\otimes w$.

**Companion status:** Runnable worked instance.

Check result: `la-sensei chapter 5` → `E05.05`.
